Build an advanced AssetGraph, RelationshipEngine, and FindingGraph that model relationships across the authorized security-assessment environment. Represent connections between domains, subdomains, IPs, certificates, web applications, URLs, API endpoints, API specifications, technologies, APKs, runtime observations, scanner results, methodology test cases, and findings, while retaining explicit scope and authorization state for every entity. Support relationships such as APK communicates with API, API belongs to application, domain resolves to IP, application uses technology, finding affects endpoint, and observation originates from test case. Create a graph-oriented interface that allows researchers to explore the attack surface, trace an API from a domain or APK, understand shared technologies, discover relationships between findings, and follow evidence provenance. Implement graph queries, relationship confidence, first-seen/last-seen tracking, and clear differentiation between confirmed relationships and inferred relationships. Never treat a graph relationship as proof of authorization; scope remains an independent security boundary. The final objective is to provide a unified visual and analytical representation of the authorized environment.
