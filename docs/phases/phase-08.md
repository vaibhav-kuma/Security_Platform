Implement the authorized reconnaissance and asset-discovery engine for domain-based targets using a plugin architecture with ScopeEngine, RateLimiter, TargetNormalizer, ExecutionPolicy, and normalized event output. Build modules for DNS discovery, subdomain discovery, DNS resolution, IP correlation, controlled service inventory, HTTP/HTTPS detection, TLS analysis, technology fingerprinting, and asset relationship discovery, and represent all discovered resources as normalized assets with first_seen, last_seen, source, confidence, scope_status, and relationship metadata. Every discovery operation must first validate the target against the project scope and must classify newly discovered infrastructure as in_scope, out_of_scope, unknown, or third_party without automatically authorizing testing merely because an asset is related to an in-scope domain. Create a ReconPlugin interface with validate, run, and normalize methods, connect it to the job system, persist results into the asset model, and stream progress to the frontend. Add deduplication, rate limiting, timeout handling, and tests using local controlled domains or fixtures rather than third-party targets. The result of this phase should be an attack-surface inventory suitable for downstream web and API analysis
