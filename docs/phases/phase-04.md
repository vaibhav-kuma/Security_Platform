Secure the platform by implementing authentication, authorization, RBAC, audit logging, session management, and core platform security controls. Use Argon2 for password hashing, secure access and refresh token handling, secure session management, password reset and email verification architecture, login rate limiting, account abuse protection, secure cookie handling, CSRF protection where applicable, and optional OAuth/OIDC integration points. Implement roles such as owner, admin, researcher, and viewer and define fine-grained permissions for projects, scopes, scans, findings, reports, and organization administration. Enforce all authorization decisions server-side and ensure users cannot access another organization’s resources through direct object manipulation or guessed identifiers. Implement append-oriented audit records for authentication events, project creation, scope changes, scan operations, finding modifications, report generation, permission changes, and security events. Add centralized security middleware, request validation, secure headers, production error handling, and tests for authentication bypass, RBAC failures, IDOR-style access control problems, token validation errors, privilege escalation, and session issues. This phase must be completed before active scanning capabilities are added because the platform must have strong security boundaries before it can control security-testing workers.
